Opção A — EmailJS (recomendada, sem servidor)

Crie conta grátis em emailjs.com → Email Services (conecte seu Gmail) → Email Templates. A Public Key do EmailJS foi feita para ficar no navegador.

No template use: {{subject}}, {{cliente}}, {{categoria}}, {{prazo}}, {{detalhes}}, {{message}} e destinatário {{to_email}}.

Opção B — Backend SMTP (Nodemailer / Resend)

Rode npm install && npm start com um .env preenchido (veja .env.example) ou faça deploy na Vercel. Senhas SMTP ficam só no servidor, nunca aqui.

Chave Gemini (opcional, para IA real)
